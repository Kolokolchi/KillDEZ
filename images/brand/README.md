# Фирменные материалы KILL DEZ

Созданы 08.10.2026 по двум изображениям концепта, предоставленным владельцем сайта. Для растровой бренд-графики использован встроенный инструмент **imagegen**, без CLI/API-скриптов. Финальные запросы сохранены в [prompts.json](prompts.json). Векторные материалы нарисованы в коде.

- `wordmark.webp` — горизонтальный логотип для шапки, подвала и меню; `wordmark.png` — исходник с прозрачностью.
- `skullbug.webp` — граффити-символ для слайдера; `skullbug.png` — исходник с прозрачностью.
- `social-card.png` — непрозрачная фирменная картинка для Open Graph-превью всех публичных страниц.
- `favicon.svg` — компактный векторный знак, нарисованный в коде в той же палитре; `apple-touch-icon.png` — его браузерный рендер 180×180 для Apple Touch Icon.
- `guide-before.svg`, `guide-after.svg` — варианты существующих векторных иллюстраций памятки в новой палитре, без изменения смысловых деталей.
- `graffiti-splatter.svg`, `graffiti-brush.svg`, `graffiti-dust.svg` — прозрачные векторные маски фоновых брызг, сухого мазка и мелкого распыла. Цвет, расположение и мягкость задаются в `css/graffiti.css`; центральная область чтения защищена затуханием. Эти SVG созданы в коде, без генерации растров.

WebP-варианты сохранены **без потерь**, с исходным альфа-каналом. Исходники PNG сохранены отдельно. Изображения не содержат клиентских данных.

Шрифт `Oswald-Variable.ttf` загружается локально. Источник — [официальный репозиторий Google Fonts](https://github.com/google/fonts/tree/main/ofl/oswald), лицензия — [OFL-Oswald.txt](OFL-Oswald.txt). Основной текст использует Arial/Helvetica. Внешние запросы к Google Fonts для действующей темы не нужны.

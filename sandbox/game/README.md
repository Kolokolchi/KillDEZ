# Песочница мини-игры: Dis Cleaning Pest Hunter

Отдельная изолированная среда для разработки, тестирования и калибровки игры для сайта Dis Cleaning.

## Содержимое песочницы

- **`index.html`** — автономная тестовая страница с реалистичным макетом сайта (шапка, баннер, услуги, контакты), плавающей кнопкой-прицелом, игровым оверлеем, HUD, экраном результатов и панелью отладки.
- **`game.css`** — оформление плавающей кнопки, игрового оверлея, анимированных SVG-спрайтов вредителей (мухи, тараканы), шлепков (splats), всплывающих очков, курсора-мухобойки и модального окна финала.
- **`game.js`** — движок игры на чистом Vanilla JS (ES6+):
  - **Реалистичная физика и спокойная скорость**: перемещения привязаны к дельта-времени `dt`, вредители ползают и летают естественно и комфортно для прицеливания (50–70 px/s), с паузами на зависание и осмотр.
  - **Босс — Крыса (Rat Boss)**: крупный вредитель с полоской здоровья (5 ударов), шевелящимся хвостом и усами. При каждом ударе крыса взвизгивает, трясёт экран, получает урон и отскакивает; при 0 HP побеждается с бонусом +100 очков.
  - **Комбо-множитель**: последовательные быстрые удары активируют множители очков (`x2`, `x3`, `x4`, `x5 🔥`).
  - **Бонус «Дихлофос»**: спускающийся аэрозольный баллончик, вызывающий волну тумана, уничтожающую всех обычных вредителей и наносящую 2 урона боссу.
  - **Web Audio API**: синтезированный реалистичный хлопок мухобойки, влажный шлепок, писк крысы, шипение аэрозоля и победный перезвон.
  - Тач/клик-детекция с расширенными хитбоксами под мобильные устройства.
  - Лид-магнит: промокод `ЧИСТОТА` (-10%) и прямая ссылка в WhatsApp.
  - Интерактивная панель отладки песочницы с ручным призывом босса и баллончика.

## Как запустить песочницу

### Вариант 1: Прямое открытие в браузере
Просто дважды кликните или откройте файл:
`d:\Anti-Gravity\Site_Disinfection\sandbox\game\index.html`

### Вариант 2: Локальный веб-сервер
В терминале:
```bash
# Через Python:
python -m http.server 3000 --directory sandbox/game
# затем открыть http://localhost:3000

# Или через npx serve:
npx serve sandbox/game
```

## Панель настроек песочницы (⚙️ в левом верхнем углу)

- **Интервал мух** — регулировка частоты появления мух (0.4s – 4.0s).
- **Интервал тараканов** — регулировка частоты появления тараканов (0.6s – 5.0s).
- **Лимит вредителей** — максимальное одновременное количество на экране.
- **Множитель скорости** — ускорение или замедление движений вредителей.
- **Длительность раунда** — 10s – 90s.
- **Быстрые кнопки:** `+5 Мух`, `+5 Тараканов`, `Раздавить всех`, `Тест финала`.
- **Симуляция экранов:** `100% (десктоп)`, `768px (планшет)`, `390px (смартфон)`.
